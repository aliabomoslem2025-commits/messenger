Telegram animated emoji assets
==============================

The files U+1F600_1.tgs.b64, U+1F602_1.tgs.b64 and U+1F923_1.tgs.b64 contain Base64-encoded gzip-compressed Lottie/TGS animation payloads sourced from the Telemoji collection:
https://github.com/saeedtahmtan/telemoji

That project credits these animation payloads to Telegram's Animated Emoji pack. These are not original artwork by this repository. Consult Telegram's current animated-emoji and sticker terms before redistributing or using these assets:
https://core.telegram.org/api/animated-emojis
https://core.telegram.org/stickers

The application decodes the Base64 and gzip layers at runtime and renders the Bodymovin JSON with Airbnb Lottie for Android (Apache-2.0).
